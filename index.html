BELUM TERHUBUNG
API key dipakai langsung dari browser untuk mengakses Intervals.icu melalui HTTPS. Secara default key hanya disimpan selama tab/sesi browser aktif. Jika memilih “Ingat”, key disimpan di localStorage perangkat ini. Jangan gunakan perangkat bersama.
Impor menerima JSON berupa array aktivitas atau objek dengan properti activities. CSV minimal memiliki kolom date, distance_km, duration_min; kolom avg_hr, rpe, type opsional. Data tersimpan lokal di browser.

Kualitas data & batasan

Runsense dapat menarik aktivitas, stream, profil atlet, dan wellness dari Intervals.icu melalui API key. Sinkronisasi dijalankan langsung dari browser; data hasil sinkron tetap disimpan di localStorage perangkat ini. Runsense tidak mengambil data Strava yang hanya tersedia di Strava. Prediksi cedera tidak dibuat karena data dan model belum tervalidasi.
